# Frontend Mobile - Immortal Campus

Aplikasi mobile (Android/iOS) untuk **Immortal Campus** (Etalase Digital Karya Ilmiah Kampus).

## Tech Stack
- **Framework:** Flutter
- **HTTP Client:** Package `http`
- **State Management:** Provider
- **Platform:** Android & iOS

## Fitur Utama Mobile (Sesuai PRD Bagian 8.2)
1. **Pencarian & Baca Karya (Publik):**
   - Eksplorasi direktori karya ilmiah, pencarian berbasis kata kunci dan filter program studi.
   - Pembaca pratinjau dokumen PDF dan pencatatan unduhan.
2. **Pemantauan Status Karya (Penulis):**
   - Melihat status verifikasi naskah secara real-time (Draft, Diajukan, Dalam Review, Perlu Revisi, Diterbitkan, Ditolak).
   - Menerima notifikasi perubahan status dan catatan kurator.
3. **Pemeriksaan Antrean Kurator (Kurator):**
   - Review ringan antrean naskah yang diajukan mahasiswa.
