ABSTRAK

Pertumbuhan volume karya ilmiah perguruan tinggi memerlukan platform repositori yang andal dan terstruktur. Penelitian ini mengusulkan arsitektur hybrid web service dengan klaster penyimpanan terdistribusi berbasis Ceph dan microservices API untuk menjamin skalabilitas akses berkas biner skripsi dan jurnal civitas akademika tanpa mengalami hambatan throughput transfer.

Bahasa Indonesia

ID / Bahasa Asal

Pertumbuhan pesat karya ilmiah digital menuntut infrastruktur repositori akademik yang berkemampuan simpan elastis dan tahan terhadap lonjakan akses multi-pengguna. Karya ini menghadirkan perancangan etalase repositori berbasis microservices dan arsitektur kluster terdistribusi. Hasil pengujian menunjukkan waktu respons API di bawah 120ms dan keberhasilan replikasi berkas 99,98% saat diuji dengan beban 5.000 permintaan konkuren.

English Abstract

EN / Translation

The rapid escalation of scholarly digital collections mandates an institutional repository framework capable of resilient elastic storage. This study introduces a distributed microservices showcase architecture integrated with redundant cluster nodes, delivering high-availability document discovery and sub-second ingestion rates.
